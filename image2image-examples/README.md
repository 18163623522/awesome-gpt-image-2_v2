# Image-to-Image Example Collection

This folder contains 10 image-to-image prompts extracted from the awesome-gpt-image-2 repository. Each subfolder contains:

- `prompt.txt`: The complete prompt text (including original Case ID and title)
- `output.jpg`: An example output image generated from the prompt
- `input.jpg`: **Placeholder position** — image-to-image requires you to upload your own reference image/photo; the original input images are not stored in the repository.

## Usage Instructions

To use these prompts, first upload the original image you want to transform/reference to GPT Image 2 / ChatGPT, then copy the content of the corresponding `prompt.txt` as your prompt. The style of the generated result will vary depending on the input image you upload.
